# 手表菜单与歌单显示回归

本次修复不修改应用版本、正式签名、账号存储格式或服务端发布记录。

## 自动化覆盖

- `WatchLayoutRobolectricTest`：API 24/35，240dp 方屏和 192/240/320dp 圆屏。
  检查长操作菜单末项可滚动、可点击，返回和 Mini Player 触控区域完整位于圆内；
  Mini Player 覆盖紧凑/标准/大字模式，播放按钮不会同时打开播放器。
  小圆屏大字模式下，选歌提交按钮随列表滚动，避免固定按钮挤掉歌曲行。
  首页标题按真实分配宽度校验，不依赖 Robolectric 对中文字形的不准确测量。
- `QqPlaylistPaginationTest`：按原始槽位而非过滤结果推进 offset；
  覆盖系统歌单、重复条目、服务端分页上限、hasMore、后页失败和异常结构。
- `LibraryApiRobolectricTest`：收藏读取失败或缺失列表字段不能伪装成空歌单；
  保留旧接口兼容回退，详情保留歌单自身封面、真实总数，并兼容旧详情 JSON。
- `PlaylistParserTest`：缺失数量为未知，明确的 0 首不得被其他字段覆盖。
- `PlaybackSettingsRobolectricTest`：失败保留账号快照和原歌单，首次失败可重试；
  同时点击刷新复用正在进行的请求，移除歌曲同步更新已知总数。

所有数据/会话均为合成测试夹具，不访问真实账号或 QQ 音乐。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

## 实机仍需核对

自动化几何和点击测试不代表所有手表均完成实机验收，也不替代截图视觉验收。
本次未启动模拟器、未登录测试账号。

- 圆屏和方屏：滚动到歌曲/队列菜单的最后一项，选择歌单及批量选歌后提交。
- 使用系统大字体，检查返回、标题、封面和播放按钮，确认没有裁切或重叠。
- 真正离线后进入收藏页：保留上次歌单并显示可重试错误，不显示错误的空态。
- 多于 100 个收藏歌单的账号：核对列表末项及顺序。
- 自定义歌单封面、未知数量和确实为空的歌单分别核对。
