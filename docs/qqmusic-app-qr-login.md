# QQ 音乐 App 扫码登录

## 用户操作

1. 在手机 QQ 音乐里登录想在手表上使用的账号，可以是 QQ 账号或微信账号。
2. 手表打开“QQ音乐扫码”，手机打开 QQ 音乐“扫一扫”。
3. 扫描手表显示的二维码，在手机端确认登录。
4. 手表根据最终凭据恢复真实账号身份，加载其资料、会员和歌单。

QQ 与微信是不同的账号身份；这项功能统一的是扫码入口，不会合并两个账号的歌单、权益或下载目录。手机 QQ 音乐扫码是默认路径，不把“微信直接扫 QQ 二维码”当作已支持的方式。

## 客户端契约

- 新通道为 `qqmusic`；旧 `qq` / `wechat` 契约保留兼容。
- 创建、轮询响应中的 `provider` 表示二维码通道。完成后的 Cookie `tmeLoginType=1|2` 才表示微信/QQ 账号，不能把二维码换凭据使用的 `6` 保存为账号类型。
- 新通道缺少账号 ID 或真实账号类型时，不保存一个猜测的 QQ 身份。
- 离开、刷新、成功、失败和过期都会尝试取消该二维码，清理请求的总超时为 3 秒。它不会注销已保存的账号。
- 已存会话、设置、队列和缓存文件不迁移，不要求已登录用户重新登录。

## 验证范围

沿用单一 app 模块和手工依赖装配；客户端用现有 JUnit4/Robolectric 验证新旧二维码契约和账号识别。服务端实现只在私有后台仓库维护，真实请求探测不打印二维码、会话 ID、票据或凭据。

二维码生成、实际监听订阅、等待查询、取消释放可独立进行无账号探测；最终授权、会员和歌单必须由用户使用真实 QQ/微信账号确认，不能用模拟成功响应代替。
