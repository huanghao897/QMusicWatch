# Android 客户端审核与修复（2026-10-18）

## 范围与原则

本次检查客户端的认证、播放恢复、缓存下载、更新文件和界面异步状态。保留单一 app 模块、现有数据格式、应用 ID 与签名。按用户前轮要求，版本已设为 0.9.15（45）；2026-10-31 后续扫码接入交付仅构建本地正式包、启用独立扫码适配器并提交代码，不再升级版本，不发布 APK 自动更新或修改服务器发布记录。

“防御过度”不是删除所有校验：应避免把临时故障当成永久失效、把可选资源失败当成核心功能失败。账号隔离、可信地址、安装包签名、存储预留和会员权限校验仍有必要。

## 已确认并修复

| 路径 | 问题与影响 | 修复 |
| --- | --- | --- |
| 登录续期 | 写操作使用规范化 Cookie 与原始会话比较，可能跳过实际续期；续期网络故障被统一转换为登录过期 | 分离会话快照和 HTTP Cookie；保留网络、限流、服务端与业务错误类型，仅明确凭据拒绝要求重新登录 |
| 认证并发 | 换号或退出后，旧请求可能重试或持久化 | 请求、结果、续期与持久化检查所属账号；仅允许同账号凭据轮换 |
| 音质降级 | 可选的登录探测临时失败阻止安全的标准音质降级 | 临时只读故障允许继续降级；取消、明确过期仍立即停止 |
| 歌曲分页 | 过滤后的空页或短页可能提前结束 | 按上游消费槽位与总数推进，保留重复页、页数和溢出保护 |
| 播放模式与进度 | 未订阅兼容状态时跳歌采用默认模式；旧歌曲恢复进度可能用于新歌；等待中的保存覆盖新歌曲 | 从持久设置读取模式；恢复进度绑定歌曲；保存捕获歌曲和会话并在写入时复核 |
| 后台恢复 | 使用出错时的播放意图，可能覆盖用户或耳机断开的暂停；替换 URL 重置恢复次数造成连续循环 | 保留实时暂停状态；同曲连续失败共享预算，实际 READY、换歌或清空媒体后重置 |
| 下载策略 | 读取旧 Wi-Fi 设置的入队可落后于设置变更；等待自动重试的任务不更新约束 | 串行化设置与入队；以 WorkManager 实际等待状态更新约束，不复活暂停任务或覆盖运行进度 |
| 下载收尾 | HTTP 416 分片持续重试；歌词写入失败或取消将已完成音频降级 | 分片最多清零恢复一次；歌词缓存尽力写入，取消向上传播，保留完整音频 |
| 安装包工件 | 下载与恢复可同时清理或写同一分片；取消请求返回后仍可能截断文件；取消校验被当作损坏而删除完整分片 | 统一工件生命周期互斥；打开文件、读取后和晋升前检查取消；取消校验保留完整分片与元数据 |
| 界面异步状态 | 旧歌词/歌单移除结果覆盖新页面；退出残留加载状态；旧提示清除新提示 | 校验歌曲、详情请求和会话；清理加载状态；按显示的消息确认消费 |
| 搜索与手表操作 | 返回搜索丢失输入；旧分类结果按新分类打开；无长按动作仍吞掉长按；偏移说明与计算相反 | 保存输入/分类；结果使用已提交分类；仅注册真实长按；纠正说明并兼容旧偏移值 |

## 验证方式与边界

- 使用现有 JUnit4、Robolectric、WorkManager 测试组件和受控 HTTP 响应验证；不引入新的依赖注入或测试框架。
- 回归覆盖认证轮换、跨账号取消、临时故障分类、分页、暂停意图、恢复预算、下载策略竞态、Range 恢复、可选歌词失败、更新文件互斥、旧 UI 结果及播放快照。
- 正式交付须通过完整单元测试、Release Lint 和 Release 构建，并复核包名、版本、非 debuggable 与既有证书。
- 本轮不启动设备/模拟器，不声称完成真实账号扫码、真实会员歌曲、蓝牙设备或手表触控验证。Snackbar 时长、搜索返回体验等仍需真机确认。
- 同步 HTTP 调用仍依赖现有网络超时退出；取消时不会再开启第二个更新文件写入者，但网络阻塞期间后续下载可能等待。
- 同曲连续恢复预算耗尽时，不自动无限重试；真实 READY、换曲或清空当前媒体可开启新周期。后续如增加显式重试入口，必须与自动恢复区分。
